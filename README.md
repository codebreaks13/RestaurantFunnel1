# RestoSIP

Restaurant stock, inventory and point of sale in a desktop app.

Record sales, manage orders and track stock movements through a restaurant desktop workflow. Reporting and backup tools support local operation.

## Technologies

React · TypeScript · Rust · Local storage

## What it does

- Sales and order workflows
- Stock movement tracking
- Reports and local backup workflows

## Current status

Desktop prototype; no customer adoption or revenue claimed.

Full implementation remains private. This showcase contains descriptions and approved demonstration material only.
