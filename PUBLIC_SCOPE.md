# RestoSIP public edition

A deliberately limited, locally runnable edition. No private server, accounts, paid AI calls, real customer records, or original workspace files are included. Browser storage is for demonstration data only.

Source is publicly viewable; this publication does not assign a blanket open-source licence or transfer commercial IP. Third-party dependencies retain their own licences.

## Reuse decision
Existing React and Vite reused (MIT); Lucide icons (ISC). Official sources: https://github.com/facebook/react, https://github.com/vitejs/vite, https://github.com/lucide-icons/lucide. No new external service. Inspect package-lock.json for the resolved dependency inventory.
